✅ Closing Stock — Actual vs System-Generated

System-Generated Closing = Opening Stock (previous date's closing) + Dispatch Received (this date) − Sales Sold (this date), compared against the Actual Closing your branch staff enter on the Ram Mandir / Vishrambagh sheet tabs. Computed fresh every time you load this tab — never a stale cached figure.

Note on Savali Factory rows: fully system-calculated (no manual closing count exists there) — the Dispatch column shows today's Production (adds to stock) and the Sales column shows today's Dispatch sent out to branches (subtracts). Status shows System Calculated instead of OK/Mismatch since there is no independent count to verify against.
